# 对抗性合规审查：个人主体红线、扫描清单与备案写法

项目的自动化测试全绿 ≠ 能过审。质量门禁查不出的是监管合规与审核驳回风险，而这恰是个人主体最容易卡住的地方。本章按「主体红线 → 扫描清单 → 备案 → 上架配置」组织。

## 目录

1. 个人主体硬边界（设计期就要绕开）
2. 对抗性扫描清单（附 grep 模式）
3. 图片版权：为什么不用网图
4. ICP 备案备注写法（含被驳回案例）
5. 微信上架四件人工事

## 1. 个人主体硬边界

- **类目**：医疗、金融、教育（资质类）、新闻、社交等类目个人主体不可选。内容型工具选「工具」或合适的资讯类目；内容里可以有医学统计教学示例，但**类目不要碰医疗**，且页内写「仅供学习，不构成医学建议」免责声明。
- **无支付**：个人主体不能用微信支付，不能有任何售卖/打赏/付费解锁。
- **无 UGC**：不能有用户发布内容（评论、上传、发帖），否则触发内容安全审核义务。
- **无诱导**：禁止「分享后解锁」「集赞」「关注公众号领资料」等诱导分享/关注。分享只能用规范 `open-type="share"`，分享是权利不是任务。

## 2. 对抗性扫描清单

用 scripts/compliance_scan.py 初筛，再人工核对上下文。各项的判定原则：

| 项 | 扫什么 | 判定原则 |
| --- | --- | --- |
| 网络与外链 | `wx.request`/`web-view`/`downloadFile`/`http(s)://` | 离线应用应为零命中；有命中则引入域名白名单与内容安全义务 |
| 敏感 API | `getUserProfile`/`getLocation`/`getPhoneNumber`/`chooseAddress`/`getWeRunData` 等 | 用到即需在隐私指引声明用途；剪贴板须走 `wx.requirePrivacyAuthorize` 且拒绝后有降级 |
| 诱导词 | 「分享得/必须分享/分享后解锁/集赞/助力/关注领取」 | 零容忍 |
| 极限词 | 「最好/最强/第一/唯一/顶级/100%/永久」 | **看语境**：「第一行代码」「唯一去重」是技术语境，不违规；宣传语里才违规 |
| 医疗敏感词 | 「诊断建议/治疗方案/用药建议/治愈/疗效/问诊」 | 教学示例语境 + 免责声明可接受；不得有任何"对用户健康给建议"的功能表述 |
| 联系方式/引流 | 「微信号/QQ/公众号/二维码/加群/私信」及变体（V信/vx） | 小程序内引流到站外是高危驳回项 |
| 商业化词 | 「付费/购买/价格/打赏/广告/商务合作」 | 个人主体应为零命中 |

**原则：词表命中不等于违规，全部要看上下文；但每个命中都必须有人工确认记录，不能扫完没看就过。**

## 3. 图片版权：为什么不用网图

个人主体没有法务缓冲，来源不明的网图是版权投诉与审核驳回最高频的两个原因。规则：

- 内容图：由内容代码真实产出（图与代码一致，版权归你）。
- 氛围图/背景图：原创生成或自绘。AI 生成后必须裁水印、压缩、逐张人工核验（无文字/无清晰人脸/无第三方品牌）。详见 references/methodology.md。
- 图标：用自带 unicode 符号或自绘 SVG，不搬第三方图标库的图片资源（用 iconfont 字体需确认授权）。

## 4. ICP 备案备注写法（含被驳回案例）

备案备注不是产品文案，是给审核员看的「服务内容说明书」。真实驳回案例：备注写「提供生物信息学Julia语言代码卡片查询服务：365张卡片覆盖……」，被电话告知"表述不安全，Julia 是什么要解释"。

被驳回的四个原因与对策：

1. **外文/缩写未解释** → 每个外文词首次出现用括号解释：「Julia 指 Julia 编程语言（一种用于科学计算的开源计算机编程语言）」。
2. **"提供××服务"的经营性口吻** → 个人非经营性备案要写「个人开发的学习参考工具，仅提供静态内容展示」。
3. **触发词未兜底**（机器学习/AI 等） → 保留术语但加「内容为预先编写的静态图文，不含人工智能生成内容，不涉及算法推荐」。
4. **生僻领域词**（如生物信息学） → 同样括号一句话解释，避免二次电话核实。

可直接套用的模板：

> 本小程序为个人开发的编程学习参考工具，仅提供静态内容展示。{外文术语}指{解释}。小程序内展示{N}张{领域}（指{领域一句话解释}）{内容形态}，内容涵盖{场景列举}，用户可按分类、关键词查阅，并可收藏。所有内容均为预先编写的静态图文，不含人工智能生成内容，不涉及算法推荐、用户注册、用户发布信息、课程售卖、在线支付及任何交易行为。

注意：**备注内容必须与小程序实际功能一致**，写上去的每一句"不涉及"都要先在代码里核实。

## 5. 微信上架四件人工事

1. **类目**：选「工具」（或贴合的资讯类目），不碰资质类类目。
2. **隐私保护指引**：按实际用到的 API 勾选（如剪贴板）；用途描述与代码行为一致。
3. **自定义分析**：用了 `wx.reportEvent` 的事件需在后台登记，否则不回传（不影响审核，影响数据）。
4. **备案号展示**：备案下发后把号填进配置，页脚展示（前端做空值隐藏，未下发前不显示空行）。
